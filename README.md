# Charette — retours publics

Ce dépôt recueille les **bugs, suggestions et autres retours des joueurs de Charette**. Il ne contient aucun code ni fichier du jeu.

[Ouvrir un retour](https://github.com/TMRomain/charette-public-feedback/issues/new/choose) · [Voir les retours existants](https://github.com/TMRomain/charette-public-feedback/issues)

Avant de créer une issue, recherchez un retour similaire puis choisissez le modèle adapté. Pour un bug, indiquez la version du jeu, le mode (solo, hôte ou client), les étapes de reproduction et les résultats attendu et observé. Une capture est facultative.

**Les textes et captures publiés ici sont publics.** Ne partagez aucune donnée personnelle, aucun mot de passe, secret ou jeton d'accès. Masquez ces informations dans vos captures.

Un bouton de feedback est prévu dans le jeu pour faciliter l'accès à ce dépôt.

Labels : `bug`, `suggestion`, `feedback` pour le type de retour ; `à trier` pour les nouveaux retours ; `solo` et `multijoueur` pour le mode concerné.
